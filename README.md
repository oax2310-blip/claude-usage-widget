# Claude 사용량 위젯 (Android)

Claude **주간 한도** 기준으로
- **하루 권장량** = 100% ÷ 초기화 주기(기본 7일)
- **지금까지 권장 누적** = 이번 주기 시작부터 지금까지 쓸 수 있는 권장 사용량 — 매일 **오전 3시**에 그날 몫이 한 번에 더해지는 계단식
- 초기화 시각이 오전 3시가 아니면 첫날·마지막날이 길이에 비례해 하루 몫을 나눠 가집니다. 예) 초기화가 토요일 오후 3시면 토 15시~일 3시(7.1%) + 일~금 하루 14.3%씩 + 토 3시~15시(7.1%) = 총 8일

을 보여주는 개인용 앱 + 홈 화면 위젯입니다. 초기화 시각만 넣으면 자동 계산되고, 현재 사용 %를 넣으면 페이스 대비 여유/초과도 표시합니다.

- 여유/초과는 **지금의 권장 누적**과 입력한 현재 사용량을 비교합니다. 오전 3시에 오늘 몫이 더해지면 위젯도 그때 다시 그려져서(최대 10분 안, 화면이 꺼져 있으면 켜질 때) 권장 누적·막대·여유/초과가 함께 바뀝니다.
- 위젯은 두 가지: 기본(4x2) 위젯과 **한 줄(5x1) 위젯**("Claude 사용량 한 줄"). 한 줄 위젯은 투명 배경에 현재 사용량을 크게 보여주고(숫자를 누르면 앱을 열지 않고 바로 입력), 권장 누적과 사용량 막대(여유면 초록, 초과분은 진한 클레이), 하루 권장·초기화까지 남은 시간을 보여줍니다. 어느 위젯이든 크기를 바꾸면 알맞은 레이아웃으로 바뀝니다.
- **자동으로 읽기(선택)**: 앱의 'Claude 로그인'에서 앱 안 화면으로 claude.ai에 한 번 로그인해 두면, 설정 → 사용량 화면이 쓰는 주소에서 **주간 사용량(%)과 초기화 시각**을 읽어 와 직접 넣지 않아도 됩니다. 앱을 열 때, 위젯 ↻를 누를 때, 위젯 자동 갱신(30분마다) 때 새로 읽습니다.
  - 공식 API가 아니라서 claude.ai가 바뀌면 멈출 수 있습니다. 그때는 직접 입력하면 됩니다.
  - claude.ai는 브라우저가 아닌 요청을 Cloudflare 확인 화면으로 막아서, 로그인 화면과 같은 WebView(크롬 엔진)를 화면 없이 띄워 읽습니다.
  - 앱 안에서는 Google 로그인이 막힐 수 있습니다. 같은 이메일 주소로 로그인 코드를 받거나, 메일의 로그인 링크를 복사해 '링크 붙여넣기'로 여세요.
  - 로그인(쿠키)은 이 앱 안에만 저장되고 claude.ai에만 쓰이며, 클라우드 백업·기기 이전에서 빠집니다. '연결 해제'를 누르면 지워집니다.
- 입력값은 폰 안에만 저장됩니다.
- 최신 APK: [ClaudeUsage.apk](../../releases/latest/download/ClaudeUsage.apk)
- 앱 안 업데이트: 새 릴리스가 있으면 앱 맨 위에 업데이트 버튼이 뜨고, 누르면 받아서 스스로 설치합니다. 처음 한 번만 이 앱에 '출처를 알 수 없는 앱 설치'를 허용하면 됩니다.
- `main`에 커밋하면 GitHub Actions(`ci/build.sh`)가 테스트·빌드 후 릴리스에 APK를 올립니다. 실패하면 로그가 이슈로 등록됩니다.
- 서명 키(`keystore/`)는 개인 사이드로드용 디버그 키입니다(업데이트 덮어쓰기 설치용).
