# Claude 사용량 위젯 (Android)

Claude **주간 한도** 기준으로
- **하루 권장량** = 100% ÷ 초기화 주기(기본 7일)
- **지금까지 권장 누적** = 이번 주기 시작부터 지금까지 쓸 수 있는 권장 사용량 — 매일 **오전 3시**에 그날 몫이 한 번에 더해지는 계단식
- 초기화 시각이 오전 3시가 아니면 첫날·마지막날이 길이에 비례해 하루 몫을 나눠 가집니다. 예) 초기화가 토요일 오후 3시면 토 15시~일 3시(7.1%) + 일~금 하루 14.3%씩 + 토 3시~15시(7.1%) = 총 8일

을 보여주는 개인용 앱 + 홈 화면 위젯입니다. 초기화 시각만 넣으면 자동 계산되고, 현재 사용 %를 넣으면 페이스 대비 여유/초과도 표시합니다. 위젯에는 **5시간 한도**(claude.ai의 '현재 세션') 사용량도 함께 나옵니다.

- 여유/초과는 **지금의 권장 누적**과 입력한 현재 사용량을 비교합니다. 오전 3시에 오늘 몫이 더해지면 위젯도 그때 다시 그려져서(최대 10분 안, 화면이 꺼져 있으면 켜질 때) 권장 누적·막대·여유/초과가 함께 바뀝니다.
- 위젯은 **한 줄(5x1) 위젯**("Claude 사용량 한 줄") 하나입니다. 투명 배경에
  - 왼쪽: 주간 사용량을 소수점 없이 크게(숫자를 누르면 앱을 열지 않고 입력 팝업이 떠서, 위쪽의 claude.ai 사용량 페이지를 보면서 한 줄 숫자 키로 바로 입력)
  - 윗줄: 권장 누적 · 여유/초과 · 오른쪽 끝에 주간 초기화까지 남은 시간
  - 가운데 막대: 주간 사용량(여유면 초록, 초과분은 진한 클레이)
  - 아랫줄: **5시간** 얇은 막대 · 사용량 · 초기화까지 남은 시간("62% · 2시간 14분 후", 10분쯤마다 다시 그림). 90%를 넘으면 빨강으로 바뀝니다. 그 5시간이 지나면 새 세션에서 얼마나 썼는지는 모르니 다시 가져올 때까지 "-- · 초기화됨"으로 보여 줍니다.
- 예전의 기본(4x2) 위젯과 1x1 게이지 위젯은 없앴습니다. 홈 화면에 놓아 두었다면 업데이트 뒤 지워 주세요.
- 앱 아이콘은 먹색 배경의 270° 게이지(클레이 호 = 사용량, 아이보리 눈금 = 권장 누적)에 가운데 흰 Claude 로고입니다(그림일 뿐 실제 값은 아님).
- 앱이 알아서 claude.ai에 접속해 사용량을 읽어 오지는 않습니다(공식 API가 없고, 자동 접근은 Claude 약관 위반). 입력 팝업을 **열었을 때만**, 화면에 뜬 사용량 페이지의 글자에서 주간 사용량(%)을 찾아 입력 칸에 채우고("가져온 값"), 같은 페이지의 5시간(현재 세션) 사용량과 초기화 시각도 함께 읽어 두었다가 **정한 시간(기본 1.2초, 앱에서 0~10초로 바꿀 수 있고 0이면 바로) 뒤 둘 다 자동으로 저장하고 닫습니다**(그 사이 숫자 키·입력 칸·페이지를 만지면 취소). 위젯의 **↻(새로고침)**를 누르면 위젯을 바로 다시 그리고 입력 팝업이 떠서, 사용량을 찾는 즉시 기다리지 않고 저장합니다. 숫자는 폰 안에서만 읽고 서버에 따로 요청하지 않습니다. 입력값은 폰 안에만 저장됩니다.
- 입력 팝업에서 처음 한 번 claude.ai에 로그인해야 합니다. 앱 안에서는 Google 로그인이 막힐 수 있어서, 같은 이메일로 로그인 코드를 받거나 메일의 로그인 링크를 복사해 '링크 붙여넣기'로 여세요. 로그인은 이 앱 안에만 저장되고 클라우드 백업·기기 이전에서 빠지며, 팝업의 '로그아웃'으로 지울 수 있습니다.
- 최신 APK: [ClaudeUsage.apk](../../releases/latest/download/ClaudeUsage.apk)
- 앱 안 업데이트: 새 릴리스가 있으면 앱 맨 위에 업데이트 버튼이 뜨고, 누르면 받아서 스스로 설치합니다. 처음 한 번만 이 앱에 '출처를 알 수 없는 앱 설치'를 허용하면 됩니다.
- `main`에 커밋하면 GitHub Actions(`ci/build.sh`)가 테스트·빌드 후 릴리스에 APK를 올립니다. 실패하면 로그가 이슈로 등록됩니다.
- 서명 키: 저장소에는 **암호화된 키**(`keystore/release.p12.enc`)만 있고, 비밀번호는 GitHub Secrets의 `SIGNING_PASSWORD`에만 있습니다(영문·숫자·기호 16자 이상). 첫 빌드 때 CI가 키를 만들어 암호화해 올리고, 이후 같은 키로 서명합니다. 비밀번호가 없거나 틀리면 빌드하지 않습니다.
  - 예전 debug 키(`keystore/debug.keystore.b64`)는 저장소에 공개돼 있어 누구나 같은 서명으로 가짜 APK를 만들 수 있어서 더 쓰지 않습니다. 키가 바뀌어서 v1.0.8 이하에서 넘어올 때는 **앱을 지우고 새로 설치**해야 합니다.
